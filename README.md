# My Catppuccin Macchiato Setup

A collection of themes and configuration files for my Windows environment, built around the **Catppuccin Macchiato** color palette.

> **Note:** This repository brings together third-party themes and personal configuration files. Original authors retain ownership of their work, and source links and credits are included where relevant.

## 🗂️ Components

| Application | Included content | Details |
|---|---|---|
| 🎨 [Discord](./Discord) | system24 Catppuccin Macchiato theme | CSS theme by [refact0r](https://github.com/refact0r/system24) |
| 🎥 [OBS Studio](./OBS-Studio) | Yami Catppuccin Macchiato variant | `Yami_CatppuccinMacchiato.ovt` |
| ⚡ [Windhawk](./Windhawk) | Nine mod configurations | Files are stored directly in `Windhawk/` |
| 🐚 [Nilesoft Shell](./Nilesoft%20Shell) | Catppuccin Macchiato shell theme | `theme.nss` |
| 💻 [Windows Terminal](./Powershell) | Windows Terminal settings and color scheme | `settings.json` |
| 🧑‍💻 [Visual Studio Code](./VS-code) | Instructions for the official Catppuccin extension | Select the Macchiato flavor |

## 🎨 About Catppuccin Macchiato

Catppuccin Macchiato is the dark, muted color palette used as the visual foundation for this setup. The goal is to keep colors and overall appearance consistent across supported applications. Individual themes may use their own layout, typography, and customization options.

## 📥 Getting started

Open the folder for the application you want to configure and follow its `README.md`. Review each file before installing it, and back up existing settings before replacing or merging configuration files.

Some themes load stylesheets or other resources from their upstream projects, so those features may require an internet connection.
