# OBS Studio - Catppuccin Macchiato Theme

This folder contains the **Catppuccin Macchiato variant of the Yami theme** for OBS Studio.

## File

- [`Yami_CatppuccinMacchiato.ovt`](./Yami_CatppuccinMacchiato.ovt) - OBS Studio theme variant.

## Installation

1. Download `Yami_CatppuccinMacchiato.ovt` from this folder.
2. Copy it into OBS Studio's themes directory, commonly:
   `C:\\Program Files\\obs-studio\\data\\obs-studio\\themes\\`
3. Open OBS Studio and go to **Settings → Appearance**.
4. Select **Yami** as the base theme and **Catppuccin Macchiato** as the theme variant.
5. Apply the changes.

If OBS Studio is installed elsewhere, use the corresponding `data\\obs-studio\\themes\\` directory.
