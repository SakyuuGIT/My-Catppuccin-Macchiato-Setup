# Windhawk - Catppuccin Macchiato

This folder contains nine configuration files for Windhawk mods that are part of my **Catppuccin Macchiato Windows setup**. All files are stored directly in this folder, not in a separate `Plugins` directory.

## Configurations

- `Windows-11-Taskbar-Styler.yaml`
- `Windows-11-Start-Menu-Styler.yaml`
- `Windows-11-Notification-Center-Styler.yaml`
- `Custom-Window-Corner-Radius.yaml`
- `Resource-Redirect.yaml`
- `Taskbar-Tray-System-Icon-Tweaks.yaml`
- `Taskbar-Auto-Hide-Speed.yaml`
- `Middle-Click-to-Close-on-the-Taskbar.yaml`
- `Alt-Tab-per-Monitor.yaml`

These are settings for individual Windhawk mods, not standalone themes. The resulting appearance depends on the corresponding mod and its supported options.

## Installation

1. Open **Windhawk** and install the mod matching the configuration you want to use.
2. Open that mod's **Advanced** settings.
3. Switch to **Text** mode, if available.
4. Open the corresponding YAML file in this folder and copy its contents.
5. Paste the contents into the mod's text configuration and apply the changes.

Only use a configuration with its matching mod. Review the contents and back up your existing settings before replacing them.
